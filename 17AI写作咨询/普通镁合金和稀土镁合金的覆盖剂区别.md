这是一个非常专业且重要的问题。普通镁合金（如 Mg-Al 系 AZ 系列，Mg-Zn 系 ZK 系列）和稀土镁合金（如 Mg-Gd， Mg-Y， Mg-Nd 等）在熔铸过程中，由于合金元素的化学性质、熔炼温度及熔体特性存在显著差异，其使用的覆盖剂在**成分、功能侧重点和具体要求**上也有很大区别。

核心区别的根本原因在于：
1.  **稀土元素的极高化学活性**：Gd、Y 等稀土元素比 Mg、Al、Zn 更活泼，极易与氧、氮、水汽反应，生成高熔点、高稳定性的氧化物/氮化物。
2.  **更高的熔炼温度**：稀土镁合金的熔炼温度通常比普通镁合金高 100-200°C（普通镁合金约 650-750°C，稀土镁合金可达 750-850°C 甚至更高）。
3.  **熔体净化难度更大**：稀土氧化物非常稳定，一旦形成固态夹杂物，极难从熔体中去除，必须从源头防止其生成。

下面从几个方面进行详细对比：

### 普通镁合金（Mg-Al， Mg-Zn）使用的覆盖剂

1.  **主要目标**：
    *   **防止镁熔体氧化和燃烧**（首要任务）。
    *   **精炼除气**（主要是 H₂）。
    *   **去除部分非金属夹杂**。
    *   **调节熔体温度**。

2.  **典型成分**：
    *   基础成分通常是**氯化物和氟化物的混合物**，如：
        *   **无水光卤石**（MgCl₂·KCl）：这是最经典和常用的基础覆盖/精炼剂，熔点约 450°C，流动性好。
        *   **MgCl₂、NaCl、KCl、CaCl₂** 等氯化物的复配盐。
        *   通常还会添加一定比例的 **MgF₂、CaF₂（萤石）** 等氟化物，以增强其与熔体表面氧化膜（MgO）的反应能力，形成更致密的保护层，并提高“润湿铺展”和分离夹杂物的能力。

3.  **特点**：
    *   **成分相对简单**，成本较低。
    *   对 Al、Zn 元素的氧化有一定的抑制能力，但并非完全针对。
    *   精炼功能主要依靠熔剂的吸附、溶解和携带夹杂物以及促进氢气逸出。

### 稀土镁合金（Mg-Gd， Mg-RE）使用的覆盖剂

1.  **主要目标**：
    *   **绝对优先防止稀土元素的氧化烧损**（这是最核心、最苛刻的要求）。稀土元素昂贵，烧损不仅增加成本，更会改变合金成分设计。
    *   **深度净化**：要求比普通合金更高，必须尽可能杜绝任何稀土氧化夹杂。
    *   **适应更高的熔炼温度**，保持长时间稳定。
    *   同时也要完成基础的保护镁熔体的任务。

2.  **典型成分与改进**：
    *   **基础熔剂体系可能类似**（仍以无水光卤石或 MgCl₂-KCl-NaCl 等为基体），但会进行重大调整：
    *   **显著提高氟化物比例**：增加 **BaF₂、SrF₂、REF₃（如 LaF₃）** 等高熔点、高反应活性的氟化物。这些氟化物能与熔体表面的 **RE₂O₃** 反应，将其转化为更易溶入熔剂层的化合物，从而**在熔体表面形成一层非常致密、连续、具有“自修复”能力的液态保护膜**，将熔体与空气彻底隔绝。
    *   **添加“稀土元素稳定剂”**：某些特定的盐类添加剂（如含锂、含硼化合物）有助于降低稀土元素在熔剂中的活性，减少其从熔体向熔剂层的转移损失。
    *   **更高的纯度和干燥度要求**：所有原料必须彻底脱水，因为水汽是导致稀土氧化的主要元凶之一。
    *   **更高的热稳定性**：配方需确保在 800-900°C 高温下不挥发、不分解、不失效，保持合适的粘度和覆盖性能。

### 总结对比表

| 特性 | 普通镁合金覆盖剂 | 稀土镁合金覆盖剂 |
| :--- | :--- | :--- |
| **核心任务** | 防燃、基础精炼、除杂 | **极致防止稀土氧化烧损**、深度净化 |
| **成分特点** | MgCl₂-KCl 为基，添加适量 MgF₂/CaF₂ | MgCl₂-KCl 为基，**大量添加 BaF₂、SrF₂、REF₃等活性氟化物** |
| **反应性** | 主要与 MgO 反应 | **必须与 RE₂O₃等高稳定性氧化物反应** |
| **工作温度** | 适应 650-750°C | 必须适应**750-850°C 或更高** |
| **保护膜要求** | 形成覆盖层即可 | 要求形成**极其致密、连续、高稳定性**的保护膜 |
| **成本** | 相对较低 | **非常高**（因含特种氟化物和更高纯度的稀土盐） |
| **精炼要求** | 常规精炼 | **超常净化**，对夹杂物（特别是 RE 氧化物）零容忍 |

### 现代熔炼工艺的补充

无论是普通还是稀土镁合金，现代先进生产越来越多地采用 **“气体保护 + 少量熔剂” 或 “全气体保护”** 的熔炼方式。
*   **保护气体**：通常使用 **SO₂、CO₂、SF₆（现因环保逐渐被淘汰）、Ar** 或它们的混合气体，与覆盖剂协同或单独使用。
*   **对于稀土镁合金**，即使使用气体保护，也常常会**在熔体表面撒布一层特种覆盖剂**，作为最后的物理化学屏障，以应对可能的气体扰动或炉门开启带来的风险。

**总而言之**，稀土镁合金覆盖剂可以看作是普通镁合金覆盖剂的“强化升级特种版本”，其所有设计都围绕“**不惜成本，锁住稀土**”这一核心目标展开，成分更复杂、活性更高、热稳定性更强、成本也昂贵得多。
