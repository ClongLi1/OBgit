## 1. 学术 PPT 制作建议 
### 1. 内容
1. 根据目标和观众组织PPT的内容
2. 层次性：整个PPT有层次性，单张幻灯片也需要考虑
3. 逻辑性：起承转合，有导入、有收尾
4. 数量：根据演讲时间确定幻灯片数量，一般来说，每张有内容的幻灯片大概需要一分钟
5. PPT不是讲稿，是提纲！

### 2. 文字 
1. 文字不宜过多：单张幻灯片不宜超过 200 字 
2. 字号不宜太小：正文字体大于 18 号，小于 36 号 
3. 自豪层级关系：标题层级
4. 行间距要合理：0.9--1.5 行距
5. 使用容易分辨的字体：微软雅黑、黑体
### 3. 颜色 
1. 单张幻灯片的颜色不宜超过五种 
2. 同类型内容采用相同的颜色 
3. 文字颜色要与背景内容形成鲜明对比（背景--文字相反颜色）
4. 背景不宜使用亮色

### 4. 图片 
1. 避免使用模糊不清的图片 
2. 避免使用带有较大 LOGO 的图片 
3. 图片上的文字最好可以辨认 
4. 图片最好与背景融合 
5. 不要使用与主题无关的插画 
6. 不要滥用模板 

### 5. 布局 
1. 不要使用太过花哨的背景 
2. 不要让内容挤在角落，要均匀
3. 不要让幻灯片塞得太满 
4. 留白尽量要匀称 
5. 不同元素之间要布局合理、审美 

### 6. 其它 
1. 尽量不要使用太玄的动画效果 
2. 尽量不要使用太玄的切换效果 
3. 尽量不要使用太玄的音频效果 
4. 音频、视频、艺术字要谨慎 
5. 幻灯片之间使用超链接要注意播放顺序 
6. 善用备注信息 
### 7. PPT 演示建议 
1. 面向观众，而不是幻灯片 
2. 不要照着幻灯片念
3. 不要只翻页，不说话，少说话 
4. 不要在一页幻灯片停留太长时间，也不要翻得太快
